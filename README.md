# وب‌اپ آب و هوا

وب‌اپ آب‌وهوای فارسی (راست‌به‌چپ) با HTML، ‏CSS و جاوااسکریپت خالص؛ بدون فریم‌ورک و بدون نیاز به کلید API.

## ویژگی‌ها

- جست‌وجوی شهر با پیشنهادهای زنده و جست‌وجوهای اخیر
- دکمهٔ «موقعیت من» با Geolocation مرورگر
- وضعیت فعلی، پیش‌بینی ساعتی و روزانه
- دادهٔ زنده از [Open-Meteo](https://open-meteo.com) (رایگان، بدون کلید)
- بنر آفلاین و نمایش آخرین دادهٔ ذخیره‌شده
- اسکلت بارگذاری و گرادیان پس‌زمینه بر اساس وضعیت هوا

## اجرا

کافی است `index.html` را در مرورگر باز کنید، یا با یک سرور استاتیک ساده اجرا کنید:

```sh
python3 -m http.server
```

بعد به `http://localhost:8000` بروید.

## ساختار فایل‌ها

- `index.html` — ساختار صفحه
- `styles.css` — استایل‌ها
- `visual.js` — جلوه‌های بصری (گرادیان پس‌زمینه، اسکلت بارگذاری، اسکرول نوار ساعتی)
- `app.js` — منطق داده: دریافت از Open-Meteo و رندر صفحه
